## 🚀 Projects

### 🟣 [Student Performance Risk Predictor](https://github.com/AryannPathak/student-performance-predictor)
> Python · Streamlit · Pandas · Scikit-Learn · Joblib

🔄 *In progress.* This web application predicts individual student academic risk status by analyzing multi-dimensional behavioral, attendance, and internal assessment metrics. Leveraging supervised classification models trained on academic tracking data, it dynamically evaluates student performance trends to surface early-warning indicators for educators.

- Real-time risk probability scoring based on attendance thresholds and continuous assessment grades.
- Interactive Streamlit dashboard interface allowing instructors to filter student segments and inspect model prediction confidence.
